A full-stack proof of concept that flags whether a credit card transaction is likely fraudulent, built on Kaggle's [Credit Card Fraud Detection dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).

## How it works

Three independent pieces, each in its own folder with its own Python environment:

```
fraud-detector/
├── training/     -> turns the raw dataset into a trained model (model.pkl)
├── backend/      -> serves that model over an API (FastAPI, port 8000)
└── frontend/     -> a web page for submitting a transaction and seeing the result (Streamlit, port 8501)
```

A person opens the Streamlit page, loads a random real transaction (or edits the values), and hits "Check transaction." The frontend sends that data to the backend API, which runs it through the trained model and sends back a prediction and confidence score.

```
[Streamlit frontend] --HTTP POST--> [FastAPI backend] --predict()--> [Random Forest model]
```

## Results

The model was trained on ~284,807 real, anonymized transactions (492 labeled fraud) and evaluated on a held-out 20% test set it never trained on:

| Metric | Fraud class |
|---|---|
| Precision | 96% |
| Recall | 74% |
| F1-score | 0.84 |

In plain terms: when the model flags something as fraud, it's right 96% of the time, and it catches 74% of all real fraud in the test set.

## Setup

### 1. Get the dataset

This repo does **not** include the dataset (it's too large for GitHub and easy to grab yourself):

1. Download `creditcard.csv` from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) (free Kaggle account required).
2. Place it at `training/data/creditcard.csv`.

### 2. Train the model

```bash
cd training
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install pandas scikit-learn joblib
python train.py
```

This prints a precision/recall report and produces two files: `model.pkl` (the trained model) and `data/test_set.csv` (the 20% of transactions held back from training — used later by the frontend so every demo example is one the model has genuinely never seen).

### 3. Run the backend

```bash
cd ../backend
python3 -m venv venv
source venv/bin/activate
pip install fastapi uvicorn joblib scikit-learn pandas
cp ../training/model.pkl .
uvicorn app.main:app --reload
```

Runs at `http://localhost:8000`. Visit `http://localhost:8000/docs` to see and test the API directly in your browser.

### 4. Run the frontend

In a **separate terminal** (the backend needs to keep running):

```bash
cd frontend
python3 -m venv venv
source venv/bin/activate
pip install streamlit requests pandas
streamlit run app.py
```

Opens automatically at `http://localhost:8501`.

## Using the app

1. Click **"Load random fraud example"** or **"Load random legitimate example"** — pulls a real transaction from the held-out test set.
2. Optionally edit the **Time** (seconds since the dataset's first transaction) or **Amount** fields — the V1–V28 fields are anonymized (PCA-transformed) and not meaningful to edit by hand.
3. Click **"Check transaction"** to get a prediction and confidence score from the model.

- This is a proof of concept, not a production system — no auth, no database, no deployment, all three pieces run locally.
